# 03 · Чек-лист взаимодействий — каждая кнопка, каждый пункт

Проверяй построчно. Каждый элемент должен делать **именно то**, что указано.
«Пустых» `onClick` быть не должно — где бэкенда ещё нет, ставь рабочую
навигацию/лист и `// TODO API`. Формат: `[ ] Элемент → действие`.

---

## Глобально — Док и FAB
- [ ] Таб **Сегодня** → экран Today (активная пилюля-подложка).
- [ ] Таб **Календарь** → экран Calendar.
- [ ] Таб **Клиенты** → экран Clients.
- [ ] Таб **Профиль** → экран Profile.
- [ ] **Центральный FAB (+)** → лист «Быстрое действие».
- [ ] Док **скрывается** на push-экранах (ClientDetail, SessionDetail,
      NoteEditor) и виден на 4 корневых табах.
- [ ] Переключение таба сбрасывает push-стек (как `goTab` в прототипе).

## Today
- [ ] Колокол (badge) в шапке → экран/лист уведомлений (заглушка ок).
- [ ] Тап по hero-карточке (вне кнопок) → SessionDetail(next).
- [ ] Кнопка **«Подключиться»** (в hero) → действие видеозвонка (`// TODO`
      открыть Zoom-intent), **не** всплывает на карточку.
- [ ] Квадратная иконка-заметка (в hero) → NoteEditor(next).
- [ ] 3 KPI-плитки → не обязательны кликом (статичны) — ок.
- [ ] «Весь день» (заголовок Расписание) → раскрыть полный список/Calendar.
- [ ] Каждая строка расписания → SessionDetail(s).

## Calendar
- [ ] Иконка **фильтр** → лист фильтров (заглушка ок).
- [ ] Сегмент **День / Неделя / Месяц / Список** → меняет представление.
- [ ] **‹ / ›** → предыдущий/следующий месяц (обновляет сетку).
- [ ] Тап по **числу дня** → выбор дня, обновляется агенда и заголовок «N июня · k сессии».
- [ ] **«Записать»** (заголовок агенды) → лист «Быстрое действие» / запись сессии.
- [ ] Строка агенды → SessionDetail.
- [ ] Пустой день → карточка «Нет записей на этот день» (без действия).

## Clients
- [ ] **«+»** в шапке → создание клиента (лист/экран, заглушка ок).
- [ ] **Поле поиска** → фильтрует список по имени вживую.
- [ ] Сегмент **Активные / Все / Архив** → фильтрует по статусу.
- [ ] Строка клиента → ClientDetail(c).

## ClientDetail
- [ ] **‹ назад** → pop.
- [ ] **⋯ меню** → меню клиента (Архивировать/Изменить/Удалить — заглушка ок).
- [ ] **«Написать»** (MessengerStatusRow, если bound) → SendMessageSheet.
- [ ] **«Пригласить»** (если не bound) → InviteSheet.
- [ ] Сегмент **Обзор/Записи/Заметки/Документы** → переключение вкладок.
- [ ] (Обзор) Баннер согласия (если consent≠ok) → SendDocumentSheet (на согласие).
- [ ] (Обзор) `SessionMini(upcoming)` → SessionDetail.
- [ ] (Записи) любой `SessionMini` (предстоящая/история) → SessionDetail.
- [ ] (Заметки) карточка заметки → NoteEditor(c, history[i]).
- [ ] (Заметки) **«+ Добавить заметку»** → NoteEditor(c, upcoming).
- [ ] (Документы) **«Отправить документ»** → SendDocumentSheet.
- [ ] Липкая **«Записать сессию»** → SessionDetail(upcoming).
- [ ] Липкая иконка-заметка → NoteEditor(c, upcoming).

## SessionDetail
- [ ] **‹ назад** → pop; **⋯ меню** → меню сессии (заглушка ок).
- [ ] Плитка клиента (в шапке) → ClientDetail(c).
- [ ] **«Заметки сессии» / «Открыть»** / тап по превью → NoteEditor(c,s).
- [ ] **Карточка напоминаний**: тап по шапке → разворот/сворачивание (шеврон 90°).
- [ ] (развёрнуто) **«Отправить ещё раз»** на строке → SendMessageSheet.
- [ ] (развёрнуто) **«Вручную»** на строке → SendMessageSheet.
- [ ] Липкая **«Подключиться»** → видеозвонок (`// TODO`).
- [ ] Липкая иконка **send** → SendMessageSheet; иконка **note** → NoteEditor.
- [ ] Липкая **«Перенести»** → лист переноса (выбор даты/времени, заглушка ок).
- [ ] Липкая **«Отменить»** (danger) → диалог подтверждения отмены.

## NoteEditor
- [ ] Сегмент **Кратко / По блокам / Голосом** → меняет тело редактора.
- [ ] Все текстовые поля → редактируются, состояние сохраняется при смене режима.
- [ ] (Голос) кнопка-микрофон → старт/стоп записи (анимация волн в записи).
- [ ] Тег-пилюля **«×»** → удаляет тег.
- [ ] **«+ тег»** → добавляет тег (поле ввода/чип).
- [ ] **«Позже»** → onBack без сохранения; **«Сохранить заметку»** → сохранить + onBack.

## Profile
- [ ] 4 тумблера автонастроек → реально переключаются и держат состояние.
- [ ] Блок «Оплата» / ссылка → копирование/открытие (заглушка ок).
- [ ] `ConnRow` Telegram / MAX → экран подключения (заглушка ок).
- [ ] 4 строки-настройки (Документы/Расписание/Тарифы/Общие) → соответствующие
      экраны (заглушка-навигация ок).

## FAB-лист «Быстрое действие»
- [ ] Затемнение/тап вне листа → закрыть.
- [ ] **Записать сессию** → запись/лист.
- [ ] **Новый клиент** → создание клиента.
- [ ] **Написать клиенту** → выбор клиента → SendMessageSheet.
- [ ] **Отправить документ** → выбор клиента → SendDocumentSheet.
- [ ] 4 строки «быстрый выбор клиента» → ClientDetail(c).

## Листы коммуникаций
**SendMessageSheet**
- [ ] 4 шаблона → подставляют текст в поле.
- [ ] (bound) **«Отправить»** → SentState «Отправлено».
- [ ] (не bound) показывается плашка + **«Подготовить»** → SentState «Готово к отправке».
- [ ] **«Отмена»** / тап вне → закрыть; **«Готово»** на SentState → закрыть.

**InviteSheet**
- [ ] Кнопки-табы **Telegram / MAX** → меняют канал и ссылку.
- [ ] **«Отправить приглашение»** → SentState(manual).

**SendDocumentSheet**
- [ ] Radio-выбор документа → выделение (рамка + галочка).
- [ ] Плашка 152-ФЗ показывается для документов с `requiresAck`.
- [ ] **«Отправить»/«Подготовить»** → SentState.

## Финальная самопроверка (agent self-check перед сдачей)
1. `./gradlew assembleDebug` — **зелёная** сборка, без варнингов компилятора.
2. Пройти по этому файлу сверху вниз — каждый `[ ]` отмечен и проверен в эмуляторе.
3. Сверить 6 экранов (Today, Calendar, Clients, ClientDetail, SessionDetail,
   Profile) со скриншотами прототипа — **док стеклянный, hero не наезжает,
   карточки стеклянные**.
4. Прогнать DoD из `README.md §4`.
