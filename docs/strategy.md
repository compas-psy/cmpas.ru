# КОМПАС — Стратегия развития продукта
## Спокойная рабочая среда для помогающих практик

`cmpas.ru/diary` | Март 2026 | Конфиденциальный документ для внутреннего использования

---

## Executive Summary

КОМПАС — это спокойная рабочая среда для помогающих специалистов (психологов, коучей, профориентаторов). Не CRM, не набор инструментов, а единое место, где специалист ведёт всю практику: от записи клиента до отслеживания прогресса.

**Позиционирование:** гибрид «спокойной рабочей среды» (бренд, глубина) и messenger-first платформы (GTM, точка входа). Веб-интерфейс — для глубокой работы, Telegram/MAX — для ежедневного удобства.

**Ключевые стратегические решения:**
- Beachhead-сегмент: растущий практик (3–7 лет, 12–25 клиентов, доход 120–300 тыс. руб./мес)
- Монетизация: 30-дневный полный триал → подписка 990 руб. (Практика) / 1990 руб. (Практика+)
- Целевой ARPU: ~1200 руб./мес, LTV: ~21 600 руб., LTV/CAC: 2.9–4.3×
- North Star Metric: сессий через КОМПАС/нед → заметок/нед → retention когорты
- GTM: community-led growth через проф. Telegram-чаты + B2B2C вирусность через клиентский кабинет
- Мессенджеры: Telegram (первый) + MAX (второй, через 3–6 мес), архитектура messenger-agnostic
- Платформы: Web (P0) → Native App (P1) → Tablet (P2); клиент: MiniApp + веб-кабинет (P0)
- Расширение: психологи → коучи → профориентаторы → нутрициологи/логопеды
- Цель 12 мес: 500 платящих пользователей, MRR 600 тыс. руб.
- Долгосрочное видение: от инструмента → к инфраструктуре помогающих практик в РФ и СНГ

## 1. Конкурентный ландшафт

Рынок вокруг КОМПАСа — это три принципиально разных мира с разной логикой.

### 1.1. Три мира конкуренции

**Мир 1: Универсальные CRM и сервисы записи**
YCLIENTS, amoCRM, OkoCRM, RubiTime, Битрикс24. Мыслят психолога как «салон красоты с одним мастером». Решают запись и воронку продаж, но не понимают терапевтический процесс.

**Мир 2: Российские специализированные**
PsyAI.pro, Lyxa AI, MegaCRM. Все думают «CRM + AI-магия» или «CRM + запись». Никто не думает как «рабочая среда терапевтического процесса».

**Мир 3: Западные эталоны**
SimplePractice ($29–$99/мес), TherapyNotes, Jane App, TheraPlatform, Practice Better. Задают планку UX, но недоступны в России.

### 1.2. Стратегическая позиция

**Ключевая пустота:** нет ни одного продукта, который одновременно даёт глубину терапевтического процесса И качество UX уровня SimplePractice.

**Конкурентные преимущества КОМПАСа:**
- Единственный продукт в РФ с Telegram-интеграцией такого уровня
- UX без «админки» — спокойная палитра, минимальный интерфейс
- Фокус на терапевтическом процессе, а не на воронке продаж
- Синхронизация с Google и Яндекс-календарями из коробки

### 1.3. Уроки от SimplePractice

| Что КОМПАС уже делает правильно | Что перенять | Что НЕ копировать |
|---|---|---|
| Спокойный UX без «админки» | Dual-app: отдельные интерфейсы | Insurance billing |
| Карточка клиента с табами | Шаблоны заметок по типу сессии | HIPAA как маркетинг |
| Расписание с режимами доступа | Measurement-Based Care: PHQ-9, GAD-7 | ePrescribe |
| Синхронизация календарей | AI Note Taker: диктовка → заметка | Website Builder |
| 30-дн. триал без карты | Load last note — предзаполнение | Wiley Planners |

## 3. Мессенджерная стратегия

### 3.1. Контекст (март 2026)
Telegram замедлен с февраля 2026, звонки заблокированы с лета 2025. MAX (VK) — национальная альтернатива, 85+ млн аудитория, предустановлен на все смартфоны.

### 3.2. Ключевое архитектурное решение

КОМПАС — это **веб-платформа с мессенджерным слоем**, не «Telegram-бот».

- Ядро (заметки, карточки, расписание, аналитика) — полностью в вебе
- Мессенджерный слой — абстракция: Telegram → MAX → SMS/email
- Первый: Telegram (inline-режим, MiniApp для клиентского кабинета)
- Второй: MAX (добавить через 3–6 мес)
- Fallback: SMS + email

### 3.3. Что идёт через мессенджер, что нет

| Через мессенджер | Только в веб-кабинете |
|---|---|
| Напоминание о встрече | Заметки специалиста |
| Подтверждение / перенос записи | Результаты диагностики |
| Ссылка на встречу | Кризисные флаги |
| Самозапись на слоты | Финансовая информация |
| Чекин «как вы сегодня» | Подробные документы и согласия |

## 5. Клиентский опыт

Клиентский кабинет — стратегический актив, источник вирусного роста.

### 5.1. Путь клиента

| Этап | Что видит | Что чувствует | Канал |
|---|---|---|---|
| Запись | Свободные слоты | Удобно, профессионально | Telegram/MAX бот |
| Напоминание | Дата, время, ссылка | Заботятся | Push / сообщение |
| Между сессиями | Задание, чекин | Сопровождают | MiniApp + кабинет |
| Оплата | Сумма, способ, история | Прозрачно | Веб-кабинет |
| Прогресс | Динамика диагностики | Вижу результат | Веб-кабинет |

### 5.2. Анти-паттерны
- Никакого gamification: нет streak'ов, бейджей
- Никаких тревожных пушей
- Приватность по умолчанию
- Опциональность: каждая фича включается специалистом для конкретного клиента
- Бережный тон: «Если будет удобно…», а не «Вы должны…»

## 6. Монетизация

### 6.1. Тарифная сетка

| | Практика | Практика+ |
|---|---|---|
| **Цена** | 990 руб./мес (790/мес за год) | 1 990 руб./мес (1 590/мес за год) |
| Клиенты | До 25 активных | Безлимит |
| Календарь, заметки, таймлайн | ✓ | ✓ |
| Синхронизация, уведомления, самозапись | ✓ | ✓ |
| Домашние задания, клиентский кабинет | — | ✓ |
| Документы, оплата, диагностика | — | ✓ |
| AI-помощник для заметок | — | ✓ |

### 6.2. Unit-экономика

| Метрика | Значение |
|---|---|
| Средний ARPU | ~1 200 руб./мес |
| Целевой LTV | ~21 600 руб. (при retention 18 мес) |
| Конверсия триал → платник | 15–20% |
| LTV / CAC | 2.9–4.3× |
| Payback period | 4–6 месяцев |

### 6.3. Стратегические решения
- Не делать бесплатный тариф — щедрый 30-дневный триал
- Годовая подписка с первого дня (скидка 20%)
- AI-помощник — повод для апгрейда на «Практика+»
- Позже: 2–3% от платежей клиентов через КОМПАС

## 9. Go-to-market

### 9.1. Два вирусных цикла

**B2B-цикл:** Марина показывает КОМПАС на супервизии → коллега регистрируется.

**B2B2C-цикл:** клиент получает задание через кабинет → рассказывает другу → тот спрашивает своего психолога.

### 9.2. Фазы роста

**Фаза 1: Первые 100 (мес 1–4)**
- 15 профессиональных Telegram-чатов
- 10–15 амбассадоров из знакомых психологов
- 5–8 custdev-интервью
- Telegram-канал с контентом (2 поста/нед)
- Реферальная программа: «приведи коллегу — оба +1 месяц»

**Фаза 2: 100 → 500 (мес 4–12)**
- Партнёрства с обучающими программами
- Telegram Ads на подписчиков релевантных каналов
- Кейсы от амбассадоров
- Запуск клиентского кабинета → B2B2C цикл
- Партнёрство с платформами (Ясно, Zigmund, Alter)

### 9.3. Каналы, которые НЕ трогать в первый год
- Контекстная реклама в Яндексе
- Instagram-реклама
- Холодные рассылки

### 9.4. Бюджет GTM (первые 6 мес)

| Статья | Бюджет |
|---|---|
| Telegram Ads | 30–50 тыс. руб. |
| Вебинарные инструменты | 10–15 тыс. руб. |
| Дизайн контента | 20–30 тыс. руб. |
| Эксперименты | 40–100 тыс. руб. |
| **Итого** | **100–200 тыс. руб.** |

## 11. Стратегическое видение

### 11.1. Пять горизонтов зрелости

| Горизонт | Суть | Метафора | Срок |
|---|---|---|---|
| 1. Инструмент | Специалист ведёт практику удобнее | Notion для психологов | 0–9 мес |
| 2. Среда | Специалист и клиент работают вместе | SimplePractice по-русски | 9–18 мес |
| 3. Платформа | Разные специалисты, одна основа | Practice Better для РФ | 18–30 мес |
| 4. Экосистема | Сервисы вокруг ядра | Супервизии, аренда | 30–48 мес |
| 5. Инфраструктура | Стандарт помогающей практики в РФ | Как YCLIENTS для бьюти | 48+ мес |

**Главная стратегическая мысль:** КОМПАС должен стать для помогающих специалистов тем, чем стал Figma для дизайнеров — не «программой», а профессиональной средой.
