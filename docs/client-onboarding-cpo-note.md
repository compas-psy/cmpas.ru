# Client onboarding product note

Рабочий принцип для флоу нового клиента психолога:

1. Психолог создает клиента.
2. Психолог добавляет первую запись.
3. Система не должна прыгать на другого клиента: фокус остается на новом клиенте до завершения первого касания.
4. После первой записи психологу предлагается отправить:
   - уведомление о записи;
   - выбранный документ/договор;
   - платежную инструкцию, если она включена.
5. Telegram получает сообщение с HTML-форматированием, скрытыми ссылками и отключенным превью ссылок.
6. MAX и ручная отправка получают чистый plain text, чтобы не показывать HTML-теги в мессенджере.
7. Открытие клиентом ссылки документа фиксирует принятие договора в журнале документов клиента.

Этот документ добавлен как CPO-напоминание: флоу должен быть быстрым, нативным для мобильного использования и юридически аккуратным для психолога.
