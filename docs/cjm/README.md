# Разбор пути (CJM)

Здесь лежат разборы пути целиком — не по одной задаче, а по всему маршруту:
экраны приложения, страницы веба, тексты автосообщений и то, куда на самом деле
ведут ссылки в них.

Разбор пишется ДО правок и утверждается учредителем. Это не отчёт о сделанном:
его смысл в том, чтобы дефекты находились здесь, а не на живом проходе.

## 2026-09-10 — «Карта пути ПРАКТИКИ»

Повод: живой проход учредителя по пути «встреча прошла → клиент записан снова»
нашёл сразу восемь расхождений — обрезанные подписи кнопок, действия, которые
предлагаются прошедшей встрече, ссылка «подтвердить», ведущая на страницу новой
записи, и по два сообщения на одну запись.

Что внутри: карта переходов по стадиям, каркасы шести экранов «как сейчас / как
предлагается», таблица всех автосообщений с проверкой «что обещает текст → куда
ведёт ссылка», тринадцать дефектов с адресами в коде и четыре продуктовые
развилки на решение учредителя.

Файл открывается в браузере как есть — внешних зависимостей, кроме шрифтов
Google Fonts, у него нет.
