# Client Channel Binding

Единый модуль привязки клиента к Telegram или MAX для сервисных уведомлений КОМПАС.

Модуль используется в Web Desktop, Web Mobile и Android. Психолог отправляет одну безопасную ссылку, клиент выбирает мессенджер и подтверждает подключение.

Подробности реализации находятся в `src/lib/channel-binding.ts`.
