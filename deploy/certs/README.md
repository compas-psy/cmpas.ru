# Дополнительные доверенные CA-сертификаты

MAX уведомил (июль 2026), что для работы ботов/мини-приложений нужно перейти на
`platform-api2.max.ru` и добавить сертификат Минцифры России как доверенный —
их инфраструктура переходит на сертификаты российского удостоверяющего центра,
которые не входят в стандартный набор корневых сертификатов Node.js/Debian.

**Как использовать:**
1. Положите сюда `.crt`/`.pem` файлы нужных корневых/промежуточных сертификатов
   (например `russian_trusted_root_ca.pem`, `russian_trusted_sub_ca.pem` — скачать
   с официального источника Минцифры/Госуслуг, НЕ из случайных источников).
2. Пересоберите и задеплойте — Dockerfile автоматически подхватит все файлы
   из этой папки, добавит их в системный trust store (`update-ca-certificates`)
   и пропишет `NODE_EXTRA_CA_CERTS`, чтобы Node.js (fetch/https) тоже им доверял.
3. Папка пуста по умолчанию — сборка не ломается при отсутствии сертификатов,
   этот шаг просто становится no-op.

Не проверено автоматически: агент не смог сам скачать сертификат Минцифры
(домены дистрибуции заблокированы в песочнице агента) и не стал воспроизводить
содержимое сертификата по памяти — это слишком рискованно для крипто-материала.
