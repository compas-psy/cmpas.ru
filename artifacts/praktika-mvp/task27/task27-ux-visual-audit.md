### Неустойчивый тест: причина найдена, тест исправлен

`src/app/diary/__tests__/dashboard.test.tsx` в первой редакции падал
примерно в половине полных прогонов. Прогон серией воспроизвёл падение
**4 раза из 8**, то есть это была не случайность среды.

Причина: тест нажимал «Скрыть» сразу после отрисовки, а `WelcomeStrip`
монтируется асинхронно — клик уходил в ещё не существующий элемент.
Исправлено ожиданием элемента (`findByTitle('Скрыть', {}, { timeout: 5000 })`)
вместо немедленного `getByTitle`. После правки: **10 запусков подряд
зелёные**, плюс два полных `npm test` (1464 passed, exit 0). Подозрение
снято, в долг не переносится.
